Detailed Description

Controladora da apresentação de backlog, responsável por interagir com o usuário e gerenciar o backlog.

  • Esta classe implementa a interface IApresentacaoBacklog e utiliza um serviço de backlog para verificar as informações do usuário. A classe interage com o usuário via terminal (ncurses), captura o email e a senha, e os valida através da camada de serviço.
