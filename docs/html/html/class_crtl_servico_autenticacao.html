Detailed Description

Implementa o serviço de autenticação de pessoas.

Esta classe realiza a seguinte operação:

  • Autenticar pessoa por email e senha

Toda interação com o armazenamento é feita por meio da interface ContainerPessoa, permitindo independência entre camada de negócio e persistência.
