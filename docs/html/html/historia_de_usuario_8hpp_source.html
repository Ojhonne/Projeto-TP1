159Utilizei o como parametro dos setters o uso da referencia
160dessa maneira não é criado copia alguma e é ultilizado a referencia daquele objeto
161o uso const antes impede do metodo alterar o valor da referencia

163Utilizei o const Tipo& nos getters pela mesma razao anterior
