Detailed Description

Controladora de apresentação responsável pelo módulo de planejamento.

Esta classe implementa a interface IApresentacaoPlanejamento e gerencia as telas e menus relacionados às entidades Projeto e PlanoDeSprint.

A controladora é responsável por capturar os dados informados pelo usuário, instanciar os domínios e entidades correspondentes e encaminhar as operações para a camada de serviço por meio da interface IServicoPlanejamento.
