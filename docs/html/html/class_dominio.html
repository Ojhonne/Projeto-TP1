Detailed Description

Classe base abstrata que padroniza o comportamento de classes de domínio.

A classe Dominio serve como base para todas as classes de domínio do sistema, fornecendo uma interface comum para validação e armazenamento de valores. As classes derivadas devem implementar o método virtual puro validar() para definir regras específicas de validação. Ela gerencia o armazenamento de uma string e garante que apenas valores válidos sejam atribuídos, delegando a regra de validação para as classes derivadas (filhas) através de um método virtual puro.
