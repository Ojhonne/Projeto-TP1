Detailed Description

Definição da controladora da apresentação Planejamento.

Author
Eduardo Sankievicz Lima

Esta controladora é responsável por gerenciar a interação com o usuário no módulo de planejamento do sistema. Ela implementa a interface IApresentacaoPlanejamento e utiliza um serviço de planejamento para realizar operações relacionadas às entidades Projeto e PlanoDeSprint. A controladora captura os dados informados pelo usuário, instancia os domínios e entidades correspondentes, e encaminha as operações para a camada de serviço.
